# Claude-skills

Semua skill Jo di satu repo: skill buatan sendiri, pihak ketiga (gstack, caveman, humanizer, elevenlabs, animasi reel, graphify) dan SKILL.md plugin di `_plugins/`.
Pasang: salin folder skill ke `~/.claude/skills/`.

Buatan Jo: accurate, devlib, devlib2-parity.
Sumber asli (lisensi masing-masing berada di foldernya):
- gstack https://github.com/garrytan/gstack (MIT)
- Caveman https://github.com/JuliusBrussee/caveman
- Humanizer https://github.com/blader/humanizer
- ElevenLabs https://github.com/elevenlabs/skills
- Animasi reel https://github.com/artemnovitckii/claude-animation-skills
- Graphify https://github.com/Graphify-Labs/graphify
- Plugin: Superpowers, Remotion, design-skills, ffmpeg-llm, local-whisper, chrome-extension-builder (hanya SKILL.md, di `_plugins/`)
