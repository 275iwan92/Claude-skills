# Claude-skills

Jo's Claude Code skills in one repo. Install: copy a skill folder to `~/.claude/skills/`.

| Folder | Content | Rule |
|---|---|---|
| `own/` | Skills made by Jo: `accurate`, `devlib`, `devlib2-parity` | Every new or changed own skill is pushed here (secret scan first). Synced daily by `claude-config/tools/sync-skills.js`. |
| `third-party/` | Skills from other authors, license kept inside each folder | Never edited here; update from the source. |
| `plugins/` | `SKILL.md` files of plugins (Superpowers marketplace, ponytail) | Reference copies only. |
